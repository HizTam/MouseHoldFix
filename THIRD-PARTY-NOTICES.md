MouseHoldFix uses the Microsoft .NET 10 runtime and Windows Forms. The self-contained
distribution includes runtime components under their respective licenses.

The self-contained package includes the actual runtime package license files
and third-party notices in its `licenses/` folder. Those files describe the
terms for the redistributed binaries; the following links describe the
corresponding open-source projects.

- [.NET runtime license (MIT)](https://github.com/dotnet/runtime/blob/v10.0.0/LICENSE.TXT)
- [.NET runtime third-party notices](https://github.com/dotnet/runtime/blob/v10.0.0/THIRD-PARTY-NOTICES.TXT)
- [Windows Forms license (MIT)](https://github.com/dotnet/winforms/blob/v10.0.0/LICENSE.TXT)

The application itself has no external NuGet package dependencies.
The MouseHoldFix icons are generated locally from the included
`scripts/New-Icons.ps1`; no external artwork is used.
